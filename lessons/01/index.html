O QUE É UM PROGRAMA?

Instruções simples → tarefas complexas

💻

O computador executa instruções simples: somar números, comparar valores, guardar dados na memória.

Um programa é uma sequência dessas instruções simples, organizadas para que o computador realize uma tarefa complexa — como rodar um jogo.

Você escreve as instruções.
O computador obedece.

A LINGUAGEM DE PROGRAMAÇÃO

Como conversar com o computador

Computadores são literais: Eles não entendem ambiguidades ou entrelinhas.
Linguagem humana é confusa: Tem muitas gírias e duplos sentidos.
A Solução: Linguagens de programação são conjuntos de comandos claros e exatos. É o "idioma" que usamos para dar vida ao jogo.

GDScript

GDScript é a linguagem oficial do Godot! Foi criada exclusivamente para desenvolvimento de jogos.

FUNÇÕES & A ENGINE

Dividindo código em blocos organizados

O computador lê o código linha por linha, dentro de blocos chamados funções.

Funções Nativas (O underline "_")

Sempre que ver uma função começando com _ (ex: _ready ou _process), significa que é uma função nativa da Engine Godot (um callback). Ela roda automaticamente em momentos específicos do jogo!

func name(args...) -> return_type:

# Roda 1 vez quando o Node entra na cena
func _ready() -> void:
    setup_level()

    # instruções...

EXEMPLO PRÁTICO

Agrupando comandos lógicos

Por que usar Funções?

  • Agrupam comandos: Juntam instruções simples para uma tarefa complexa.
  • Evitam repetição: Permitem usar o mesmo bloco de código várias vezes.
  • Organizam: Deixam o projeto muito mais fácil de ler.

O nome da função não pode ter espaços, acentos, ou palavras reservadas.

Exemplo.gd
●●●
func fazer_cafe() -> void:
    # O computador não sabe fazer café sozinho.
    # Nós agrupamos o passo a passo:
    ferver_agua()
    colocar_po_de_cafe(2)
    passar_agua_no_filtro()

A FUNÇÃO PRINT()

Exibindo mensagens no console

O GDScript oferece algumas funções utilitárias já prontas. Uma das mais usadas é o print().

Esta função recebe um texto ou valor como argumento e o exibe no painel Output (Saída) do Godot. É essencial para debugar (testar) nosso jogo!

Script.gd
●●●
func _ready() -> void:
    print("Hello, Godot!")
    print("Meu primeiro script!")
Output
Hello, Godot!
Meu primeiro script!

VARIÁVEIS & TIPOS

Caixinhas para guardar nossos valores

Pensem em variáveis como "caixinhas" na memória. Damos um nome e um tipo para guardar um valor específico.

int Números Inteiros (ex: -1, 0, 10).
float Números Decimais (ex: 2.5, 9.1).
bool Valores Lógicos/Booleanos (true, false).
String Textos (ex: "player").
Variaveis.gd
●●●
func _ready() -> void:
    # 1. Com tipo e valor (Recomendado)
    var level : int = 3
    
    # 2. Apenas o tipo (valor padrao atribuido)
    var speed : float
    
    # 3. Inferência (Engine adivinha o tipo)
    var player_name = "Hero"
    
    var is_jumping : bool = false

ARGUMENTOS

Enviando valores para funções

Quando uma variável é declarada dentro de uma função, ela só existe dentro daquele bloco.

Para que outras funções saibam os valores da variável, precisamos enviar o valor (Argumento) da função que chama para a que recebe.

A função receptora precisa especificar o nome e o tipo de dado que espera receber, igual a uma variável!

Argumentos.gd
●●●
func _ready() -> void:
    var num = 4
    print_number(num) # Chamando e enviando


# Função que recebe um (num) do tipo inteiro
func print_number(num: int) -> void:
    print(num)

func _ready() -> void:
    var x = true
    var y = false
    var z = 83
    
    var a = x and y
    # a = false (pois y é false)
    
    var b = x or y
    # b = true (pois x é true)
    
    var c = not x
    # c = false (oposto de true)
    
    var d = z == 30 + 53
    # d = true (83 é igual a 83)
    
    var e = z > 100
    # e = false (83 não é maior que 100)

RETORNO DE VALORES

Funções que processam e devolvem um resultado

Agora que sabemos como processar variáveis, podemos criar uma função que processa um valor e retorna um resultado para quem a chamou.

Na declaração da função, precisamos especificar o tipo do valor retornado usando a seta -> tipo:.

Lembre-se: quando uma função encontra a palavra return, ela termina seu processo e se torna o próprio valor!

Return.gd
●●●
func _ready() -> void:
    var result = add(8, 7)
    print(result) # Saida: 15


# Funcao que recebe inteiros e retorna um inteiro
func add(a: int, b: int) -> int:
    return a + b
Output
15

ESTRUTURAS CONDICIONAIS

O poder de decisão do seu código (if, else e elif)

Para criarmos uma estrutura condicional, usamos a palavra if (se) seguida de uma condição booleana. O código só entra naquele bloco se a condição for verdadeira.

if Se a condição for True, executa.
else Senão (Se o IF anterior falhar), executa.
elif Senão se (Tenta outra condição se a primeira falhar).

REPETIÇÃO: FOR

Repetindo uma ação um número exato de vezes

A forma mais comum de usar o for no Godot é para repetir uma ação um número exato. Usamos a função range().

  • for: Avisa o Godot "Comece a repetição!".
  • i: É o nosso "índice" contando. Variável automática para saber em qual repetição estamos.
  • in range(3): É o limite de vezes (0, 1, 2).
ForLoop.gd
●●●
func _ready() -> void:
    for i in range(5):
        print(i)
Output

REPETIÇÃO: WHILE

O loop condicional (Enquanto...)

Repete um bloco de código enquanto uma condição for verdadeira. Imagine o while como um if que se repete sem parar até a condição falhar!

Cuidado com Loops Infinitos!

A condição dentro do while deve eventualmente se tornar false! Caso contrário, o jogo vai travar para sempre executando aquele bloco.

💖 health: 3
WhileLoop.gd
●●●
func _ready() -> void:
    var health = 3
    
    while health > 0:
        print("Ainda estou vivo!")
        health -= 1
Output

DESAFIO!

Juntando todo o conhecimento

Crie uma função chamada battle() que simule uma luta contra um monstro!

  • Crie variáveis para a vida do monstro (ex: 30) e seu dano de ataque (ex: 10).
  • Use um while que continue a luta enquanto a vida do monstro for maior que zero.
  • Dentro do laço, subtraia o seu dano da vida do monstro (use -=).
  • Ainda no laço, use um if/else: se a vida chegar a 0 imprima "Monstro Derrotado", senão imprima a vida restante.
